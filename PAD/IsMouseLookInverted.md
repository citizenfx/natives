## IS_MOUSE_LOOK_INVERTED

```c
// 0xE1615EC03B3BB4FD
BOOL IS_MOUSE_LOOK_INVERTED();
```

Gets whether the mouse look is inverted.

## Return value
Returns `true` if the mouse look (Y-axis) inversion is enabled in the game settings, and `false` otherwise.
